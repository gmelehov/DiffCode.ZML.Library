## Что планируем сделать

### Доработки репозиториев перед финальной сборкой

#### ZMLProject
Убираем избыточный слой Builders и IBuilderService.  
Переносим дефолтные вычисления (XType, Layout, базовые отступы) прямо в соответствующие классы моделей (Checkbox, Grid, Panel и т.д.).  
Избавиться от папки Builders, сервиса BuilderService и интерфейса IBuilderService.  

Рефакторинг JSExpressionsService: замена таблиц словарей на Pattern Matching.  
Заменить громоздкие словари на современные C# switch expressions (сопоставление с образцом по типам кортежей).  


Декларативное чтение атрибутов XML.  
Делаем свойства с ленивой инициализацией по типу:  
```cs
public bool AutoLoad => GetBool("autoload", defaultValue: false);
public int PageSize => GetInt("pageSize", defaultValue: 25);
```

Чистим Utils.cs, но обязательно оставляем функционал для компиляции ItemTemplates (они точно будут нужны, т.к. используются внутри некоторых важных компонентов).  


#### DiffCode.JSGenerator
Пока оставляем все как есть - его XML-парсер, иерархию бинарных операций НЕ меняем. Что с ними делать дальше - будем думать потом.

DiffCode.JSGenerator - название оставляем
